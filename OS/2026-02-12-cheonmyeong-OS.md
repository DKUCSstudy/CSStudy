# ✨ 학습 주제

- 과목: OS
- 주제: 3. 운영체제 (운영체제와 컴퓨터, 메모리, 프로세스와 스레드, CPU 스케줄링)

## 📄 학습 내용 요약

### 3.1 운영체제와 컴퓨터
- **운영체제의 역할**: 자원 관리, 프로세스 및 장치 관리, 사용자 인터페이스 제공, 시스템 보호.
- **컴퓨터의 요소**: CPU, 메모리, 입출력 장치 등으로 구성되며, 운영체제는 이들을 효율적으로 제어합니다.

### 3.2 메모리
- **메모리 계층**: 레지스터, 캐시, 주기억장치(RAM), 보조기억장치(HDD/SSD) 순으로 속도와 가격이 다르며, 이를 계층적으로 구성하여 성능을 최적화합니다.
- **메모리 관리**: 가상 메모리, 세그멘테이션, 페이징 등을 통해 한정된 메모리를 효율적으로 분할하고 보호합니다.

### 3.3 프로세스와 스레드
- **프로세스**: 실행 중인 프로그램. 컴파일 과정을 통해 실행 파일이 생성되고 메모리에 로드됩니다.
- **프로세스 메모리 구조**: 코드, 데이터, 힙, 스택 영역으로 나뉩니다.
- **PCB (Process Control Block)**: 프로세스의 정보를 저장하는 구조체입니다.
- **스레드**: 프로세스 내의 실행 단위로, 자원을 공유하며 효율적인 멀티스레딩이 가능합니다.
- **임계 영역(Critical Section)**: 공유 자원에 접근하는 영역으로, 교착 상태(Deadlock)를 방지하기 위한 동기화가 필요합니다.

### 3.4 CPU 스케줄링 알고리즘
- **비선점형**: 프로세스가 스스로 CPU를 반납할 때까지 기다리는 방식 (FCFS, SJF 등).
- **선점형**: 운영체제가 강제로 CPU를 회수할 수 있는 방식 (RR, SRTF, 다단계 큐 등).

## 🔍 추가 학습 필요사항

- 가상 메모리의 페이지 교체 알고리즘(LRU, LFU 등)이 실제 모던 OS에서 어떻게 구현되는지 더 시뮬레이션해보고 싶습니다.
- 교착 상태 방지 알고리즘인 은행원 알고리즘의 복잡도와 한계에 대해 더 공부할 예정입니다.

## 💡 리뷰어에게 질문
