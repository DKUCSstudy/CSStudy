## 📄 학습 내용 요약

### 트랜잭션
- 정의: 데이터베이스에서 하나의 논리적 기능을 수행하는 작업의 단위
- 연산: 커밋(트랜잭션의 변경 사항을 DB에 적용)과 롤백(트랜잭션 취소)
- 특성: **ACID**
    - 원자성: all or nothing
    - 일관성: 허용된 방식으로 데이터를 변경
    - 격리성: 트랜잭션이 서로 끼어들지 못함
    - 지속성: 성공한 트랜잭션은 영구적으로 저장되어야 함
- 격리 수준
    - SERIALIZABLE
        - 트랜잭션을 순차적으로 진행시킴
        - 가장 엄격한 격리 수준
    - REPEATABLE_READ `(MySQL 기본값)`
        - 어떤 트랜잭션이 수정한 행을 다른 트랜잭션이 수정할 수 없음
        - 새로운 행을 추가하는 것은 막지 않는다 &rarr; <u>팬텀 리드 현상 발생</u>
    - READ_COMMITTED `(PostgreSQL, Oracle 기본값)`
        - 커밋 완료된 데이터만 조회를 허용한다.
        - 어떤 트랜잭션이 접근한 행을 다른 트랜잭션이 수정할 수 있음
        - <u>반복 가능하지 않은 조회 현상 발생</u>
    - READ_UNCOMMITTED
        - 커밋되지 않은 데이터도 조회할 수 있음
        - <u>더티 리드 현상 발생</u>

### 무결성
- 정의: 데이터의 정확성, 일관성, 유효성을 유지하는 것
    - 개체 무결성: 기본키는 null이 아니어야 한다.
    - 참조 무결성: 참조 관계의 두 테이블은 일관성을 유지해야 한다.
    - 고유 무결성: 고유 값을 갖도록 설정된 속성의 값들은 고유해야 함
    - NULL 무결성: not null 속성은 null이 아니어야 함
