## 📄 학습 내용 요약

### 1. 관계형 데이터베이스
- 테이블 형식의 데이터를 저장하는 데이터베이스
- SQL 언어로 조작
1. MySQL
    - B-Tree 기반 인덱스
    - 스레드 기반 메모리 할당
    - 빠른 조인
    - 최대 64개 인덱스
    - 대용량 데이터베이스
    - 데이터 웨어하우징
    - 고가용성
    - 쿼리 캐시
2. PostgreSQL
    - VACUUM
    - 최대 테이블 크기 32TB
    - JSON을 통한 접근
    - 중첩된 트랜잭션

### 2. NoSQL 데이터베이스
1. MongoDB
    - Document 기반 데이터베이스
    - JSON을 통한 데이터 접근
    - Binary JSON으로 데이터 저장
    - 높은 확장성
    - 빅데이터에 특화된 성능
    - 고가용성
    - 샤딩
    - 레플리카셋
    - 스키마 필요 없음
    - ObjectID
2. Redis
    - 인메모리 데이터베이스
    - 키-값 데이터 모델 기반 데이터베이스
    - 활용 사례
        - pub/sub을 통한 채팅 시스템
        - 캐싱
        - 세션 정보 관리
        - 실시간 순위표
